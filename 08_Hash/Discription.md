# 8-1 해시

## 🧩 해시(Hash)란?

해시란 **임의의 길이를 가진 데이터를 고정된 길이의 값**으로 변환하는 것.  
이때 사용되는 함수는 **해시 함수(Hash Function)**, 변환된 값은 **해시 값(Hash Value)** 또는 **해시 코드(Hash Code)**라 부름.

---

## 🔍 해시의 주요 활용

- **빠른 검색**: 해시 테이블 사용 시 평균 O(1) 시간에 데이터 탐색 가능
- **데이터 무결성 검사**: 해시 값을 비교해 데이터 변조 여부 확인
- **보안**: 비밀번호 저장, 디지털 서명 등 암호화 영역에 사용

---

## ⚙️ 해시 함수의 핵심 조건

- **결정성(Determinism)**: 같은 입력 → 항상 같은 출력
- **효율성(Efficiency)**: 계산이 빠름
- **균등 분포(Uniformity)**: 데이터가 고르게 분포돼야 충돌 적음
- **충돌 최소화**: 서로 다른 입력이 같은 해시 값을 갖지 않도록

---

## 🐍 파이썬에서 해시

- `dict`, `set` 등의 내부 구조는 해시 기반
- 키를 해시하여 **버킷** 위치 결정 → 빠른 데이터 접근 가능

# 📘 8-2 해시 함수

## 🧠 해시 함수는 일대일 대응이어야 한다?

엄밀히 말하면, **이상적인 해시 함수**는 서로 다른 입력에 대해 **서로 다른 해시 값(충돌 없음)**을 생성해야 합니다. 하지만 현실에서는 **해시 테이블 크기가 유한**하기 때문에 **충돌(Collision)**이 발생할 수밖에 없습니다.  
따라서 실제 해시 함수는 **충돌을 최대한 줄이는 것**이 핵심입니다.

---

## 🔧 자주 사용하는 해시 함수

### 🔹 나눗셈법 (Division Method)

- **공식**: `h(k) = k mod m`  
- `k`: 키, `m`: 해시 테이블의 크기  
- `m`은 **소수(prime number)**를 사용하는 것이 좋음  
  - 이유: 데이터가 특정 패턴을 가질 때, 소수가 아니면 해시 값이 특정 영역에 **치우쳐** 분포할 수 있음 → **충돌 증가**
- 해시 테이블 크기 `m`은 **충분히 크고 소수**로 설정하는 것이 일반적

### 🔹 곱셈법 (Multiplication Method)

- **공식**: `h(k) = ⌊m * (kA mod 1)⌋`  
- `A`: 0과 1 사이의 실수 (일반적으로 `A ≈ (√5 - 1)/2 ≈ 0.618`)  
- **특징**: `m`이 2의 거듭제곱이어도 충돌 분포가 나쁘지 않음  
- **하드웨어 구현에 유리**

### 🔹 문자열 해싱 (String Hashing)

- 문자열을 해시 값으로 변환하는 방식  
- 자주 쓰이는 방식:
  ```
  h(s) = (s₀ * p⁰ + s₁ * p¹ + s₂ * p² + ... + sₙ₋₁ * pⁿ⁻¹) mod m
  ```
  - `sᵢ`: i번째 문자(정수형 변환), `p`: 보통 31 또는 53, `m`: 큰 소수  
- **충돌 방지**를 위해 **이중 해싱** 또는 **다항 해싱** 활용

---

## 📌 요약

- 해시 함수는 **충돌을 최소화**하고, **효율적 계산**이 가능해야 함
- 해시 테이블 크기는 일반적으로 **충분히 큰 소수**로 설정
- 문자열 해싱은 정수 해싱보다 충돌 가능성이 높아 더 정교한 설계 필요
